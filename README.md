🎵 Music or Magic

Live Demo: https://takshpatel26.github.io/Music-or-Magic/

📖 About
Music or Magic is a web application that plays different songs depending on the hand gestures detected by your webcam. It is an interactive project that combines coding, creativity, and machine learning.

💡 Motivation
I wanted to build something fun and interactive that reacts in real-time to user actions. I also wanted to explore **hand gesture recognition** and see how humans and computers can interact.

🛠 Tech Stack
- HTML  
- CSS  
- JavaScript  
- ML Hand Detection (via TensorFlow.js or other ML libraries)

🚀 Features
- Detects left or right hand using webcam  
- Plays different songs depending on the hand gesture  
- Real-time response to gestures

🧩 How It Works
1. Open the website and allow webcam access  
2. Place your hand in front of the webcam  
3. Left hand → plays *Peter Pan Song*, Right hand → plays *Harry Potter Theme*  
4. The hand detection model identifies gestures and triggers music automatically

⚡ Future Improvements

- Make the UI more interactive
